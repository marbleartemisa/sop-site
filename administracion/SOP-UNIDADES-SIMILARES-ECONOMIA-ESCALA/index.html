1. OBJETIVO 

Establecer un procedimiento estándar para identificar, consolidar, diseñar, programar, 
fabricar e instalar proyectos repetitivos de: 

• 

cabinetry,  

• 

closets,  

• 

vanities,  

• 

cocinas,  

• 

baños,  

• 

countertops,  

• 

stone surfaces, etc  

garantizando: 

• 

economía de escala,  

• 

reducción de tiempo de diseño,  

• 

optimización CAD/CAM y CNC,  

• 

fabricación eficiente por lotes,  

• 

reducción de desperdicio,  

• 

control de variaciones reales de obra,  

• 

estandarización operativa entre departamentos.  

2. PRINCIPIO GENERAL 

En proyectos multifamiliares, comerciales o repetitivos, las unidades NO deben tratarse 
como proyectos completamente independientes cuando existen configuraciones iguales 
o altamente similares. 

La operación debe estructurarse bajo: 

• 

diseño por MODELOS,  

• 

programación por SIMILARIDAD,  

• 

fabricación por LOTES,  

• 

control de variaciones menores,  

• 

máxima reutilización de ingeniería y programación.

4. DEFINICIONES 

4.1 Modelo Base / Base Model 

Configuración estándar repetitiva dentro del proyecto. 

Ejemplos: 

• 

Kitchen Type A  

• 

Kitchen Type B  

• 

Vanity Type C  

• 

Countertop Type D  

 

4.2 Variación Menor / Minor Variation 

Diferencia que NO requiere nueva ingeniería completa ni nueva lógica de programación. 

Ejemplos: 


PROYECTOS CON UNIDADES SIMILARES Y ECONOMIA DE ESCALA 

 

 

 

Page 4 of 13

 

 

• 

fillers ±1"–2", (Espacio/pieza de compensación) 

• 

pequeñas diferencias de pared,  

• 

ajustes por fuera de escuadra,  

• 

scribes (elemento o margen de ajuste utilizado para absorber irregularidades de 
paredes, pisos o techos durante la instalación, evitando modificaciones 
estructurales del modelo base),  

• 

backsplash adjustments,  

• 

side splash adjustments,  

• 

pequeñas tolerancias de instalación.  

4.3 Variación Mayor / Major Variation 

Cambio que rompe la lógica del modelo base. 

Ejemplos: 

• 

cambio de layout,  

• 

cambio de appliances,  

• 

modificación estructural,  

• 

cambio de profundidad,  

• 

cambio de sink,  

• 

cambios de seams,  

• 

reubicación de plumbing,  

• 

alteraciones funcionales.  

5. RESPONSABILIDADES POR DEPARTAMENTO 

5.1 Ventas / Estimación 

Objetivo 

Identificar desde negociación los proyectos repetitivos y proteger la economía de escala 
desde el inicio. 

Responsabilidades 

• 

Identificar tipologías repetitivas.

• 

Negociar bajo lógica modular y producción masiva.  

• 

Definir tolerancias aceptables.  

• 

Establecer criterios de variación menor.  

• 

Informar expectativas de producción repetitiva.  

Reglas 

NO vender proyectos repetitivos como: 

• 

“fully custom individual units”.  

Debe existir: 

• 

matriz preliminar de tipos,  

• 

cantidad de repeticiones,  

• 

acabados,  

• 

excepciones conocidas.  

5.2 Técnico de Medidas / Field Measure 

Objetivo 

Tomar medidas reales SIN destruir la estandarización. 

Procedimiento 

A. Clasificación de Tipologías 

Cada unidad debe identificarse como: 

• 

Type A,  

• 

Type B,  

• 

Type C, 
etc.  

B. Validación de Repetición 

Antes de crear nueva ingeniería preguntar:

• 

¿La unidad pertenece a un modelo existente?  

• 

¿La diferencia es menor o mayor?  

C. Conservación del Modelo 

Las diferencias menores deben absorberse mediante: 

• 

fillers,  

• 

scribes,  

• 

backsplash,  

• 

side splash,  

• 

tolerancias controladas,  

• 

ajustes de instalación.  

D. Escalamiento 

Solo generar nueva tipología cuando: 

• 

cambia estructura,  

• 

cambia funcionalidad,  

• 

cambia modulación,  

• 

cambia programación CNC,  

• 

cambia fabricación base.

Diseñar sistemas repetibles, modulares y paramétricos. 

Reglas Generales

B. Concentrar Variables 

Las diferencias deben limitarse a:

•

•

• 

toe kicks,  

• 

backsplash,  

• 

side splashes.  

NO rediseñar cajas completas innecesariamente. 

C. Programación CNC / CAD-CAM 

La programación debe priorizar: 

• 

reutilización de piezas,  

• 

reutilización de nested patterns,  

• 

reutilización de toolpaths,  

• 

mínima reprogramación,  

• 

mínima cantidad de setups.

5.4 Stone / Countertops / Solid Surfaces 

Objetivo 

Maximizar reutilización de plantillas, programación y fabricación por lote. 

Principio General 

Pequeñas diferencias NO deben convertir cada countertop en una pieza completamente 
nueva. 

Las variaciones deben absorberse mediante: 

• 

backsplash,  

• 

side splash,  

• 

fillers,  

• 

overhang tolerances,  

• 

ajustes controlados.

• 

diferencia ≤ 1"–2",  

• 

pared fuera de escuadra leve,  

• 

pequeñas variaciones de profundidad,  

• 

ajustes ocultos contra pared.

5.5 Revisión y Aprobación 

Objetivo 

Proteger la economía de escala durante todo el proyecto. 

Toda aprobación debe evaluar: 

1. Impacto Productivo 

• 

¿Rompe el modelo?  

• 

¿Genera nueva programación?  

• 

¿Incrementa setups?  

• 

¿Aumenta desperdicio?  

• 

¿Afecta producción en lote?

2. Clasificación del Cambio 

Cambio Menor 

Se absorbe dentro del modelo. 

Cambio Mayor 

Debe justificarse formalmente. 

3. Registro de Excepciones 

Toda excepción debe documentarse: 

• 

unidad,  

• 

motivo,  

• 

responsable,  

• 

impacto.  

5.6 Producción 

Objetivo 

Fabricar por lotes y familias repetitivas. 

Procedimiento 

A. Agrupación 

Producción debe consolidar: 

• 

piezas iguales,  

• 

módulos repetitivos,  

• 

puertas iguales,  

• 

piezas stone similares,  

• 

componentes estándar.  

B. Separación de Variables

•

•

•

C. Minimización de Setups 

Priorizar: 

• 

menos cambios de herramienta,  

• 

menos cambios de material,  

• 

menos reprogramación,  

• 

mayor repetición de procesos.  

5.7 Instalación 

Objetivo 

Resolver variaciones menores en campo SIN destruir la economía de escala. 

Responsabilidades 

Instalación debe absorber pequeñas variaciones mediante: 

• 

fillers,  

• 

scribes,  

• 

backsplash,  

• 

side splash,  

• 

siliconado,  

• 

ajustes controlados.  

 

No se debe solicitar refabricación por: 

• 

pequeñas diferencias previstas,

•
