SOP – GESTIÓN Y CONTROL DE CUENTAS POR COBRAR (ACCOUNTS RECEIVABLE) 

 

1.  Nombre del Procedimiento 

SOP-ADM-002– GESTIÓN Y CONTROL DE CUENTAS POR COBRAR 

2.  Objetivo. 

Establecer un proceso estandarizado para el control, seguimiento y recuperación de cuentas por 
cobrar (Accounts Receivable), garantizando el flujo de caja, la responsabilidad compartida y la 
trazabilidad de las gestiones de cobro. 

3.  Alcance 

Aplica a: 

• 

Departamento de Contabilidad (Accounting)  

• 

Vendedores / Sales Representatives  

• 

Gerencia  

Incluye todas las Sales Orders con saldo pendiente. 

4.  Definiciones Clave 

Sales Order (SO): 

Documento generado en Quickbooks, una vez que el cliente acepta un estimado. Constituye 
un  compromiso  de  ambas  partes.  A  partir  de  ese  momento,  cualquier  saldo  pendiente  se 
considera cuenta por cobrar 

5.  Responsabilidades 

5.1.  Contabilidad (Accounting) 

• 

Generar y distribuir reportes semanales  

• 

Actualizar pagos recibidos  

• 

Registrar motivos de saldos pendientes  

• 

Apoyar gestiones de cobranza cuando sea requerido

5.2.  Vendedores 

•

6.  Procedimiento Operativo 

6.1.  Envío De Reporte Semanal 

 

 

 

 

 

 

 

 

 

 

 

 

 Frecuencia: Semanal (cada lunes) 

 

 

 

 

 

 

 

 Hora límite: Antes de las 4:00 PM 

Responsable: Contabilidad 

Acción: 

• 

Enviar a cada vendedor un archivo Excel con:  

o 

Todas las Sales Orders con saldo pendiente  

o 

Información actualizada de cuentas por cobrar  

6.2.  Gestión Del Vendedor 

 

 

 

 

 

 

 

 

 

 

 

 

 Periodo de gestión: Lunes → Viernes 

 

 

 

 

 

 

 

 Fecha límite de entrega: Viernes 12:00 PM 

Cada vendedor debe: 

1.  Revisar su reporte completo  
2.  Actualizar el mismo archivo Excel incluyendo:  

o 

Estado del proyecto  

o 

Estatus del pago  

o 

Acciones realizadas de cobranza  

o 

Fecha estimada de pago (si aplica)  

o 

Indicación clara si la cuenta:  

▪ 

Está lista para cobro inmediato  

▪ 

Requiere seguimiento adicional  

3.  Documentar TODA gestión realizada:
