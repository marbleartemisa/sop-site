1. OBJETIVO 

Establecer  el  procedimiento  operativo  para  el  seguimiento  de  clientes  potenciales, 

administración  de  proyectos  vendidos,  control  documental  y  coordinación  operativa 

entre  ventas,  diseño,  producción,  compras  e  instalación,  utilizando  Houzz  Pro  como 

plataforma principal de gestión. 

Este procedimiento tiene como finalidad: 

• 

Maximizar el tiempo efectivo de venta del vendedor.  

• 

Liberar al vendedor de tareas administrativas y operativas.  

• 

Garantizar seguimiento continuo a clientes y proyectos.  

• 

Evitar pérdidas de oportunidades comerciales por falta de seguimiento.  

• 

Mantener control documental y operativo de cada proyecto.  

• 

Detectar y corregir retrasos antes de que impacten al cliente.  

• 

Estandarizar la comunicación y control interno.  

• 

Garantizar cumplimiento de fechas comprometidas.  

2. ALCANCE 

Este procedimiento aplica para: 

• 

Leads o clientes potenciales.  

• 

Clientes anteriores.  

• 

Contratistas y aliados estratégicos.  

• 

Proyectos vendidos.

4.1. FUNCION: SOPORTE PARA SEGUIMIENTO DE VENTAS POTENCIALES Y NUEVOS 

PROYECTOS.  

El  Asistente  será  responsable  de  registrar  y  dar  soporte  en  el  seguimiento  de  leads  y 

nuevos proyectos.

la via que acuerden, cada nuevo cliente potencial o Nuevo proyecto de un cliente anterior, 

detallando según aplique la siguiente informacion: nombre del cliente, telefono, email, si 

es un lead o un cliente anterior y la direccion. 

El Ejecutivo Comercial indicará si la relacion con este cliente, la manejara directamento o 

si  el  asistente  puede  comunicarse  con  el  cliente  para  requerir  informacion  necesaria, 

adicional o faltante para el proyecto y coordinar tareas futuras como medida, instalacion, 

punchout etc.

2.Caso Cliente anterior o Contratista con Proyecto Potencial. 

Independientemente de los niveles de lealtad y alta probabilidad de que se concreten 

las  nuevas  ventas  de  clientes  anteriores  o  contratistas,  estos  proyectos  potenciales 

deben ser sometidos a un similar proceso de seguimiento, con el objetivo de planificar 

los  tiempos  y  evitar  que  a  ultima  hora,  el  cliente  quiera  ser  atendido  con  premura, 

interfiera con otros proyectos y afecte nuestra capacidad fisica de atencion.  

Ser  proactivos  en  la  planificacion  de  los  trabajos  de  nuestros  clientes  regulares,  nos 

puede ayudar a evitar tiempos de poco trabajo y otros de alta demanda. 

En el caso de contratistas y aliados estrategicos, el seguimiento se realizará, presionando 

por la necesidad de que el trabajo se realice sin presion de ultima hora.  

Para el cliente el tiempo corre desde el primer dia que hizo contacto.  “El cliente 
cuenta el tiempo desde que comenzó a pensar en el proyecto”.

3. Caso Proyecto Vendido 

Es importante siempre elaborar el Gantt del Proyecto, a partir de las tareas necesarias 

en cada caso y teniendo en cuentas las siguientes normas: 

•  Una vez que el proyecto esta vendido es muy importante dar seguimiento a 

cada etapa, garantizando cumplir la fecha de entrega prometida al cliente. 

•  Ante  eventuales  retrasos  por  mercaderia  en  backorder,  problemas  del 

proveedor etc, hay que registrar task para notificar al cliente del imprevisto, ver 

si desea cambiar de opciones o acepta esperar por el tiempo requerido. 

•  Toda  tarea  debe  tener  una  fecha  de  terminacion  y  debe  verifcarse  su 

cumplimiento en esa fecha. 

•  Manejar tareas paralelas, priorizando las que mas tiempo demandan, ejemplo 

pintura,  importacion  de  hardware  etc.  Estas  tareas  por  su  carácter  critico 

respecto al tiempo de cumplimiento deben tener un seguimiento especial
