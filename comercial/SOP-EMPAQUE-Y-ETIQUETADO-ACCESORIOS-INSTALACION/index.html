SOP EMPAQUE Y ETIQUETADO DE ACCESORIOS PARA INSTALACIÓN 

 

1. OBJETIVO 

Establecer un procedimiento estándar para el empaque, identificación y entrega de todos 
los accesorios pequeños y medianos requeridos durante una instalación, garantizando 
que el instalador pueda identificar rápidamente el contenido, el proyecto al que pertenece 
y la persona responsable del proyecto. 

 

2. ALCANCE 

Este  procedimiento  aplica  para  todos  los  proyectos  que  requieran  items  o  accesorios 
pequeños o medianos, necesarios para la instalación tales como: 

• 

Handles  

• 

Cam Locks  

• 

Shelf Pins  

• 

Screws  

• 

Brackets  

• 

Hinges  

• 

Clips  

• 

Cover Caps  

• 

Fasteners  

• 

Special Hardware  

• 

Repuestos  

• 

Cualquier accesorio mediano o pequeño 

3. RESPONSABILIDADES 

Vendedor 

• 

Definir todos los accesorios necesarios para el proyecto.  

• 

Entregar la información correcta al coordinador de instalaciones.

• 

Reportar inmediatamente cualquier diferencia.  

4. ESTÁNDAR DE EMPAQUE 

Todos los accesorios deberán almacenarse en una única bolsa plástica resistente (tipo 
Kirkland o equivalente). 

La marca de la bolsa no es obligatoria; lo importante es que cumpla con las siguientes 
características: 

• 

Bolsa transparente.  

• 

Resistente.  

• 

Reutilizable.  

• 

Tamaño suficiente para contener todos los accesorios.  

• 

Fácil de transportar.  

No se permite entregar accesorios sueltos. 

5. INFORMACIÓN OBLIGATORIA EN LA ETIQUETA 

Cada bolsa deberá tener una etiqueta visible ubicada en la parte exterior. 

La etiqueta deberá contener: 

Project Name 

Ejemplo: STEVE ABA PO 9107 SW 137 Terrace

7. BENEFICIOS DEL ESTÁNDAR 

Este procedimiento permite: 

• 

Reducir pérdidas de accesorios.  

• 

Evitar mezclar piezas entre proyectos.  

• 

Facilitar la identificación de materiales.  

• 

Reducir llamadas innecesarias.  

• 

Mejorar la organización del proceso de instalación.  

• 

Aumentar la productividad del instalador.  

• 

Disminuir retrasos durante la instalación.  

9. NO CONFORMIDADES 

Se considera incumplimiento cuando: 

• 

Se entregan accesorios sin bolsa.  

• 

La bolsa no tiene etiqueta.  

• 

La información de la etiqueta está incompleta.  

• 

Los accesorios pertenecen a otro proyecto.  

• 

Existen varias bolsas pequeñas cuando podría utilizarse una sola.  

• 

No aparece el nombre del vendedor responsable.
