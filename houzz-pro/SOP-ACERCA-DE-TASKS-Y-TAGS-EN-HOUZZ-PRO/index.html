SOP SOBRE TASKS Y TAGS EN HOUZZ PRO 

1.  Objetivo 

Establecer un estándar para la creación y utilización de Tasks y Tags dentro de Houzz Pro con el 
fin  de  mantener  todos  los proyectos  organizados,  facilitar  los filtros,  mejorar  la  comunicación 
interna y controlar el avance de cada etapa. 

2.  Conceptos 
2.1. 

¿Qué es un Task? 

Un Task es una actividad que alguien debe realizar, y por ello debe serle asignada. 

Siempre tiene: 

• 

Responsable  

• 

Fecha  

• 

Estado  

• 

Prioridad  

• 

Checklist (opcional)  

• 

Fotos e informacion anexa (opciona) 

Ejemplos 

✓ Tomar medidas 

✓ Fabricar gabinetes 

✓ Aprobar shop drawings 

✓ Programar instalación 

✓ Cobrar saldo final 

2.2. 

¿Qué es un Tag? 

Un Tag es una etiqueta. No representa trabajo. Sirve únicamente para clasificar información.

2.3. 

La diferencia más importante 

TASK = Algo que alguien hace. 

TAG = Información para clasificar. 

Nunca utilizar un Tag como si fuera un Task. 

Incorrecto Tag:  "Call Customer" 

Correcto Task: Call Customer 

 

3.  Cuando crear un TASK 

Crear un Task cuando exista alguna de estas condiciones: 

✓ Alguien debe realizar una acción. 

✓ Existe una fecha límite. 

✓ Se requiere seguimiento. 

✓ El proyecto no puede avanzar sin esa actividad. 

 

4.  Cuando crear un TAG 

Crear un Tag cuando la información sirva para clasificar el proyecto, etapas, controles etc. 

5.  Estándar de Creación de Tasks 

Todos los Tasks deberán comenzar con un verbo.

7.  Responsables 

Cada  Task  debe  tener  únicamente  un  responsable  de  su  ejecución.    Nunca  dejar  Tasks  sin 
responsable.
