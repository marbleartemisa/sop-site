Paso 1: Para agendar una instalación 

1.  Abre el menú de búsqueda: Haz clic en el ícono de la lupa (Search) en la barra lateral 

oscura de la izquierda.  

2.  Entra al calendario general: En la sección 

Management

, selecciona la opción Schedule 

Overview.  

 

 

 

3.  Activa la vista de equipo: En la barra superior, haz clic en el ícono de la persona junto a 

un calendario para abrir la vista Team Calendar.

Paso 2: Llenar los datos de la instalación 

1.  Título (

Add title): Escribe el nombre de la tarea o instalación (ej. Installation Day 

- Nombre del Cliente) y presiona el botón negro de verificación (✓) para guardarlo. 

Con esto se activa el registro de la Tarea.

 

 

2.  Proyecto  (

Search  &  Select  Project/Lead): 

Busca  y  vincula  el  cliente  o  proyecto 

correspondiente para que el calendario quede 

asociado a su expediente. 

3.  Ubicación (

Add location): Confirma o agrega 

la  dirección  exacta  donde  se  realizará  el 

trabajo. 

4.  Fechas y horario (

All Day): Por defecto viene 

marcada  la  casilla  All  Day.  Desmárcala  para 

habilitar  las  casillas  de  hora  y  así  poder 

ingresar la fecha de inicio (

Start Date), fecha de 

fin (

End Date) y el horario exacto de la cita. 

5.  Notas  (

Description):  Agrega  cualquier 

instrucción clave para el instalador (códigos de 

acceso,  materiales  especiales  o  detalles  del 

trabajo). 

6.  Color (

Color): Selecciona el círculo del color asignado para identificar visualmente 

el tipo de tarea en el calendario. 

7.  Guardar:  Cierra  o  guarda  la  ventana  para  que  la  cita  quede  bloqueada  en  el 

calendario del instalador.
