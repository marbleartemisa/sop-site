SOP – VEIN AND BOOK MATCHING 

 

I. 

OBJETIVO 

Establecer  un  procedimiento  estandarizado  para  la  inspección,  documentación  fotográfica, 
evaluación y aprobación del diseño de vetas (Book Match y Vein Match) antes del inicio de la 
fabricación, garantizando el mejor resultado estético del trabajo, aprovechamiento optimo del 
material y el cumplimiento de las politicas de revision y aprobaciones establecidas. 

II. 

ALCANCE

III. 

DEFINICIONES 

Book Match 

Disposición espejo de dos o más slabs consecutivos para obtener un patrón perfectamente 
simétrico. 

Es una técnica donde dos (o más) slabs consecutivos son abiertos como si fueran las páginas 
de un libro. 

Generalmente provienen del mismo bloque de piedra.

Cuando  el  segundo  slab  se  gira  180°,  las  vetas  forman  una  imagen  espejo  perfectamente 
simétrica. 

Es lo que vemos en paredes de lujo, TV Walls, lobbies de hoteles, etc. 

La mayoría de fabricantes etiquetan estos juegos de slabs como 

• 

A-B  

• 

A-B-C-D  

• 

1-2-3-4  

para indicar el orden correcto. 

Vein Match 

Alineación  estratégica  de  las  vetas  entre  piezas  distintas  para  crear  continuidad  visual.No 
necesariamente busca simetría. Busca continuidad. 

La idea es que las vetas parezcan atravesar una unión. 

Por ejemplo 

•  Countertop-Backsplash 
•  Waterfall-Island 

Todo parece provenir de una sola pieza.  El cliente no debe percibir dónde está la unión. 

Esto requiere planificar el corte antes de fabricar. 

Slip Match (opcional) 

En  algunos  porcelánicos  las  piezas  se  colocan  consecutivamente  sin  invertirlas.  Las  vetas 
continúan en la misma dirección. 

Open Book 

Posición final de dos slabs abiertos como un libro.

V. 

PROCEDIMIENTO 

1. Venta del Servicio 

Durante la venta ofrecer al cliente las opciones especiales de matching para aumentar la 
estética del resultado. 

Si  el  cliente  no  lo  desea,  Artemisa  realizará  el  layout  utilizando  los  mejores  criterios 
profesionales. 

2. Inspección del Material 

Cada slab deberá inspeccionarse cuidadosamente. 

Buscar 

• 

cracks  

• 

fissures  

• 

pin holes  

• 

resin repairs  

• 

chips  

• 

edge damages  

• 

color variations  

• 

warpage  

• 

manufacturing defects  

Todo defecto deberá registrarse. 

5. Marcación de Imperfecciones 

Las imperfecciones deberán marcarse utilizando cinta o marcador de color visible para la 
cámara. 

Nunca marcar directamente sobre superficies delicadas.

VI. 

Consideraciones de Fabricación según el Equipo de Corte 

A. Fabricación en Breton CNC 

La  Breton  es  el  método  preferido  para  proyectos  de  Book  Match  y  Vein  Match  cuando  la 
geometría, tamaño de las piezas y programación lo permitan. 

Ventajas 

Precisión repetitiva. 

Cortes perfectamente rectos. 

Compensación automática del diámetro del disco. 

Menor error humano. 

Mayor control de ángulos. 

Excelente para continuidad de vetas.

Recomendaciones 

1. Mantener el sistema de coordenadas 

No modificar el origen del programa una vez aprobado el layout. 

Un pequeño cambio puede desplazar toda la continuidad del diseño. 

2. No invertir piezas accidentalmente 

Es muy común que durante la programación una pieza quede: 

• 

espejada  

• 

rotada 180°  

• 

rotada 90°  

Antes de ejecutar el programa debe verificarse que la orientación digital coincida 
exactamente con la orientación aprobada por el cliente. 

3. Identificación física 

Cada pieza cortada debe marcarse inmediatamente con: 

• 

Proyecto  

• 

Pieza  

• 

Orientación (TOP)  

• 

Cara vista  

• 

Número de slab  

Nunca confiar únicamente en la memoria del operador. 

4. Mantener el mismo kerf 

Todas las piezas que forman continuidad deben considerar exactamente el mismo ancho 
de disco. 

Una diferencia de apenas 2 mm puede alterar la posición de una veta importante.

5. Evitar cambios de referencia 

Si  una  pieza  debe  recortarse  nuevamente,  deberá  posicionarse  utilizando  las  mismas 
referencias originales. 

6. Dry Layout 

Antes  del  acabado  final  se  recomienda  presentar  las  piezas  juntas  para  confirmar  la 
continuidad del diseño.

2. Trazado extremadamente preciso 

Las líneas de corte deben verificarse dos veces. 

En piezas de continuidad estética una desviación mínima puede romper el diseño. 

3. Mantener referencias 

Después del primer corte deben conservarse referencias para el resto de las piezas. 

4. Verificar escuadra frecuentemente 

La escuadra de la máquina deberá comprobarse periódicamente. 

Una desviación de apenas 0.5° puede hacerse evidente en un waterfall.

1

Waterfalls

• 

TV Walls

VII. 

Consideraciones Especiales para Waterfall 

Este es probablemente el punto donde más errores se cometen. La unión debe planificarse 
antes del corte. 

El operador debe confirmar: 

•  Dirección de la veta. 
•  Sentido de caída. 
•  Orientación de la cara vista. 
•  Espesor final. 
•  Posición del miter. 

En un waterfall la veta debe "caer" naturalmente. 

No debe verse como dos piezas independientes. 

VIII. 

Consideraciones especiales para Book Match 

Nunca separar físicamente un par Book Match sin identificación. 

Las piezas deberán permanecer: 

• 

numeradas  

• 

orientadas  

• 

almacenadas juntas  

Si el proyecto se detiene, el orden deberá conservarse.

XII. 

Opciones cuando NO existen slabs Book Match 

Aquí es donde realmente se nota la experiencia del diseñador. 

Aunque el fabricante no haya producido un juego A-B o A-B-C-D, es posible construir un efecto 
muy convincente mediante: 

• 

rotación de slabs (90° o 180°, según el material);  

• 

inversión horizontal o vertical durante el diseño digital;  

• 

selección de zonas específicas de dos slabs distintos con vetas compatibles;  

• 

continuidad de líneas principales entre countertop, backsplash y waterfall;  

• 

ocultar las transiciones en juntas o esquinas cuando la continuidad perfecta no sea posible.  

En estos casos el objetivo ya no es una simetría absoluta, sino lograr que el observador perciba el 
conjunto como un diseño continuo y natural.
